# Excitement Compass

A free, private web app that helps you find what excites you most right now, act on it, and let go of the outcome.

It runs in the browser and stores nothing on any server. Everything you write stays on your device.

> Work in progress. The build plan is in [SPEC.md](SPEC.md).

## Run it locally

There is no build step. Serve the folder with any static server, for example:

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000.
